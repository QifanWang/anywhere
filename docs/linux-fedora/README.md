# Fedora 文档（预留）

此处将放置 `INSTALL.md`，记录 Fedora 上的工具安装与注意事项。

预计包管理器：dnf（部分工具需要 COPR 或 cargo，例如 `cargo install eza yazi-fm`）。

通用命令速查见 `../CHEATSHEET.md`；配置文件按工具放在 `../../config/`（如 `../../config/tmux/`、`../../config/eza/`），链接脚本为 `../../scripts/shared/bootstrap.sh`。Fedora 的安装脚本放到 `../../scripts/linux-fedora/`。
