# 命令速查（按工具）

本目录把原来单一的 `CHEATSHEET.md` 按工具拆分，只保留命令、按键与仓库配置差异。安装步骤见 `../win11-toolchain.md` 与 `../linux-fedora-toolchain.md`，两平台差异见 `../toolchain.yaml`。

| 工具 | 速查文档 | 适用平台 |
| --- | --- | --- |
| RMUX | `rmux.md` | 仅 win11 |
| tmux | `tmux.md` | 非 win11（Linux / WSL） |
| eza | `eza.md` | win11 / linux-fedora |
| glow | `glow.md` | win11 / linux-fedora |
| yazi | `yazi.md` | win11 / linux-fedora |
| helix | `helix.md` | linux-fedora 实测；win11 只链接配置 |

> win11 使用 RMUX 而不是 tmux。两者都保持默认前缀键 `C-b`。
